How CyberRAG Works

The complete end-to-end data processing and query execution flow.

01

Cybersecurity Documents

Upload PDFs, Word (.docx, .doc), markdown notes, OWASP documentation, or MITRE ATT&CK materials.

02

Text Processing

Extract clean text and structure from uploaded documents while stripping noise.

03

Chunking & Metadata

Split documents into overlapping semantic chunks tagged with source name, page numbers, and IDs.

04

Embedding Generation

Convert text chunks into high-dimensional vector representations capturing semantic meaning.

05

ChromaDB Vector Store

Store vectors, raw text snippets, and document metadata inside persistent ChromaDB collections.

06

Student Question

Student submits a cybersecurity query via the modern interactive chat interface.

07

Similarity Search

Execute vector distance match in ChromaDB to retrieve top matching document chunks.

08

Gemini 3.6 API Generation

Supply retrieved context and query to Google Gemini with a Cybersecurity Assistant prompt.

09

Grounded Response

Display structured answer in CyberRAG chat alongside transparency steps and source citations.

System Architecture

Cybersecurity Use Cases

Explore what cybersecurity topics students can master using CyberRAG.

Web Security

OWASP Vulnerabilities

Deep-dive into SQL Injection, Cross-Site Scripting (XSS), CSRF, SSRF, Broken Access Control, and remediation code.

Threat Intel

MITRE ATT&CK Framework

Explore adversary tactics (Initial Access, Execution, Persistence) and specific sub-techniques like PowerShell execution.

Networking

Network Security Protocols

Understand OSI vs TCP/IP models, TCP 3-way handshakes, UDP streaming, DNS spoofing, and ARP poisoning attacks.

OS Security

Linux Hardening & IR

Learn SUID permissions, SSH hardening, `/var/log/auth.log` analysis, and NIST Incident Response lifecycle phases.

Crypto

Cryptography Essentials

Study symmetric vs asymmetric encryption (AES-256, RSA), SHA-256 hashing, TLS 1.3 handshakes, and JWT authentication.

Exam Prep

Security Revision & Q&A

Prepare for cybersecurity course exams and security certifications (CompTIA Security+, CEH, EJPT, CISSP concepts).
